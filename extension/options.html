Jev Voice の設定

この画面で、拡張とローカルサーバーを接続します。次回からは Brave のツールバーにある Jev Voice アイコンをクリックすると開けます。

  1. ローカルサーバー jev-voice を起動します。
  2. プロジェクト内の .voice-token ファイルを開き、中の文字列をコピーします。
  3. 下の「ペアリングトークン」欄に貼り付け、「保存」を押します。
  4. 「マイクを許可・確認」を押し、ブラウザの許可画面で許可します。

ここに保存するのは接続用トークンです。OpenAI の API キーは入力しません。
